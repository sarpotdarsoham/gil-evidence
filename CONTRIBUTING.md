# Contributing

This experimental project is maintained on a best-effort basis. There is no support service or stability guarantee. Open a minimal source example with expected and observed analysis results; do not include credentials or private repository code.

Run `python3 -I -S -B run_tests.py` before proposing a change. Add regression cases for behavior changes. Preserve the frozen pre-refinement analyzer and matrix: changes to current analysis must not rewrite historical evaluation definitions. Record whether evaluation data were already used during development.

Keep claims scoped to the implemented model. A candidate requires contextual verification before being described as a project defect. Contributions and AI assistance must be represented accurately. The project uses the MIT license.
